# 001

001 应用（WebView 壳），当前版本 **v1.0.3**。

## 主要功能

- **免翻地址入口**：内置三个永久免翻地址（数据来自 [xunse.org](https://xunse.org/) 发布页），一键进入论坛
- **内置浏览器**：论坛在 App 内 WebView 打开，登录、站内跳转等所有链接均留在壳内，不再跳转外部浏览器
- **附件下载**：支持论坛附件下载（系统 DownloadManager）
- **图片上传**：支持拍照 / 相册选图上传
- **地址失效兜底**：三个地址都进不去时，可一键前往发布页获取最新地址
