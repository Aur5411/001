# 第一会所sis001

001 应用（WebView 壳），当前版本 **v1.1.1-fix**。

## 功能

- 启动页可直接粘贴整段文字，自动识别其中的网址（含不带协议的域名）
- 并发探活后直接进入可用线路，全部不通回退站点主域名
- 记住上次成功的地址，下次启动直达
- 论坛站内打开，`target=_blank` / `window.open` 转当前窗口
- 附件下载、拍照 / 相册选图上传
- 登录正常化：修正 WebView 给同源 AJAX 附加的 `X-Requested-With`（避免被判为 App 请求返回 418）
- UA 归一为手机版 Chrome；可选粘贴电脑端 Cookie 直接进登录态
- 全站去点击高亮、切页流畅
