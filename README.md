# 第一会所sis001

001 应用（WebView 壳），当前版本 **v1.1.1-fix**。

## 功能

- 启动页支持**直接粘贴整段文字**，自动从中文说明里识别出所有网址
- 点「进入」后并发探活，**哪条线路通就直接进哪条**，不再先撞死线路闪错误页
- 记住上次成功的地址，下次启动直达
- 论坛在 App 内打开，登录与站内跳转都留在壳内；`target=_blank` / `window.open` 链接改为当前窗口跳转
- 附件下载、拍照 / 相册选图上传
- **登录正常化**：修正 WebView 给同源 AJAX 自动附加的 `X-Requested-With: <包名>` 头（浏览器不会发这个值，会被站点判为 App 请求并返回 418）
- UA 归一为手机版 Chrome，保留真实内核版本号
- 可选：粘贴电脑浏览器登录后的 Cookie，直接以登录态进入
- 全站去点击高亮、切页流畅

## 更新记录

### v1.1.1-fix

- **全败兜底改为 `https://www.sis001.com/bbs/`**：所有候选地址都探不通时直接落到站点主域名，不再落到 IP 镜像
- 启动页预填地址同步改为 `https://www.sis001.com/bbs/`；探活排序不再把 sis001.com 当坏线路压低优先级

### v1.1.0-fix

- **整段粘贴自动识别网址**：正则从任意文本里捞 `http(s)://` 与裸域名 / 裸 IP，中文说明、序号、标点全部忽略；多个地址粘成一条长串（`…/forum/http://154.84.5.196/bbs/…`）也能正确切开。实测用户原帖一段中文裹着 9 条地址 → 精确识别 9 条，无垃圾条目
- **探活后再加载**：4 线程并发 GET（9 秒预算，HTTP 200~399 判活），测通哪条直接进哪条，从根上消除「先闪一下错误页再跳进去」；全部失败回退实测可用的 `http://104.194.212.41/bbs/`
- 输入框改为 3~8 行多行显示、可滚动，长文本直接粘贴
- 网络判断不再只认 WIFI / 蜂窝 / 以太网（VPN、代理下不再误判「没有网络」而彻底不加载）
- 去掉诊断悬浮层注入：不再挡住页面底部 38%，也不再给跨域 XHR 加 `X-Requested-With` 导致预检失败
- `target=_blank` / `window.open` 统一改为当前窗口跳转，论坛链接点了不再没反应
- 版本号 1.0.5 → 1.1.0-fix（versionCode 3 → 8）

### v1.0.5

- 启动页改为**手动输入网址**进入，并记住上次输入的网址
- **修复登录提交 418**：WebView 会给页面发出的每个 XHR / fetch 自动加 `X-Requested-With: <本应用包名>`（浏览器永远不会发这个值），站点防护据此判为「App 请求」并返回 418，导致登录提交、验证码初始化全部失败；现改为浏览器实际会发的 `XMLHttpRequest`（仅同源请求）
- UA 归一为干净的手机版 Chrome，保留真实内核版本号
- 每次页面加载后主动把 Cookie 落盘，减少 Cloudflare 重复验证（该验证为站点自身策略，App 无法绕过）
- 移除内置固定地址与自动探测

### v1.0.4

- 修复点击元素偶尔出现黄色高亮框：提前注入时机、样式加固、覆盖同源 iframe、被页面重写后自动补回

### v1.0.3

- 启动页改为三个免翻地址按钮；修复登录被外跳浏览器；去掉点击黄框（初版）
