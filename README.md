# 第一会所sis001

001 应用（WebView 壳），当前版本 **v1.0.5**。

## 主要功能

- **手动输入网址进入**：启动页手动填写论坛网址，点「确认网址并进入」；下次打开自动回填上次填的网址
- **内置浏览器**：论坛在 App 内 WebView 打开，登录、站内跳转等所有链接均留在壳内，不再跳转外部浏览器
- **附件下载**：支持论坛附件下载（系统 DownloadManager）
- **图片上传**：支持拍照 / 相册选图上传
- **登录正常化**：修正 WebView 给 AJAX 请求自动附带的 `X-Requested-With: <应用包名>` 头（浏览器不会发这个值，会被站点防护判为 App 请求并返回 418），解决「登录提交 418」「验证码提示缺少参数」等问题
- **请求头归一**：UA 换成干净的手机版 Chrome（保留真实内核版本号），避免「UA 声称的版本与实际渲染引擎不一致」
- **可选 Cookie 导入**：可直接粘贴电脑浏览器登录后的 Cookie，以登录态进入
- **无点击高亮**：全站去除点击元素的黄色高亮框与焦点轮廓（含 iframe 内的登录框、编辑器）
- **流畅优化**：关闭窗口切换动画、强制硬件加速，切页不卡顿

## 更新记录

### v1.0.5
- 启动页改为**手动输入网址**进入：单行网址输入 + 「确认网址并进入」按钮；输入过的网址会被记住，下次打开自动回填
- **修复登录无法提交**：WebView 会给页面发出的每个 XHR / fetch 自动加上 `X-Requested-With: <本应用包名>`，而浏览器永远不会发这个值；站点防护据此判定为「App 请求」并返回 **418**，导致登录提交、验证码初始化全部失败。现在在页面脚本执行之前把它改成浏览器实际会发的 `XMLHttpRequest`（仅作用于同源请求，避免影响第三方脚本）
- 请求头 UA 归一为干净的手机版 Chrome（保留真实 Chrome 内核版本号）
- **关于 Cloudflare 人机验证**：这是站点自身的安全策略，App 侧无法绕过。本版做了两处收敛以减少重复验证：AJAX 头修正不再作用于跨域请求（不干扰验证脚本）、每次页面加载后主动把 Cookie 落盘（避免放行凭据 `cf_clearance` 因进程被杀而丢失）
- 移除内置固定地址与自动探测（探测请求本身会被站点防护当作异常流量）
- 可选：把电脑浏览器登录后的 Cookie 粘贴进启动页，直接以登录态进入

### v1.0.4
- 彻底修复点击元素偶尔出现黄色高亮框的问题：
  - 注入时机从「页面加载完成」提前到「加载进度 10% / 首帧可见」，加载慢的页面不再有窗口期
  - 去高亮样式加固（提升优先级、拆分规则，避免被站点主题样式覆盖或整条失效）
  - 覆盖同源 iframe（登录框、编辑器等）内的点击
  - 样式被页面重写后自动补回（DOM 监听 + 低频轮询 + 交互兜底）
  - 关闭 WebView 原生焦点高亮

### v1.0.3
- 启动页改为三个免翻地址按钮
- 修复登录被外跳浏览器的问题
- 去掉点击黄框（初版）、优化切页动画与流畅度

## 安装说明

本安装包与**官方原版**、以及 **v1.0.4 及更早改版**所用的签名**均不相同**（本版换用了新的签名密钥）。

> **安装本版前，请先卸载手机上已有的 001**（官方原版或旧改版）。直接覆盖安装会因签名不一致而失败。
